      ☁️ Sincronización Multi-Dispositivo en Tiempo Real (Supabase Cloud)

      Conectá la aplicación a una base de datos PostgreSQL serverless gratuita (Supabase) para sincronizar todos tus datos en vivo entre tu PC, celular y tablet al usar GitHub Pages.

      📍 Copiala desde Supabase → Project Settings → API → Project URL. Si termina en /rest/v1 no hay problema, se limpia automáticamente.
      🔑 Copiala desde Supabase → Project Settings → API → Project API Keys → anon public.
      📖 Guía rápida: Cómo inicializar las Tablas Relacionales en Supabase (SQL Editor)
      1. Ingresá a supabase.com y abrí tu proyecto.
      2. En el panel izquierdo ve a SQL Editor, abre un New Query, copia todo el contenido del archivo database/schema_postgresql.sql de tu proyecto y haz clic en Run.
      3. Para otorgar permisos públicos RLS a las tablas relacionales, ejecuta este comando: 
        -- Otorgar permisos RLS a las tablas del sistema relacional
GRANT ALL ON ALL TABLES IN SCHEMA public TO anon, authenticated;
GRANT ALL ON ALL SEQUENCES IN SCHEMA public TO anon, authenticated;

-- Habilitar politicas publicas en tablas relacionales
ALTER TABLE empresas ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Publico Empresas" ON empresas FOR ALL USING (true) WITH CHECK (true);
ALTER TABLE locales ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Publico Locales" ON locales FOR ALL USING (true) WITH CHECK (true);
ALTER TABLE roles_empleados ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Publico Roles Empleados" ON roles_empleados FOR ALL USING (true) WITH CHECK (true);
ALTER TABLE empleados ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Publico Empleados" ON empleados FOR ALL USING (true) WITH CHECK (true);
      4. Copiá la Project URL y la anon key desde Project Settings -> API y pegalas arriba.
